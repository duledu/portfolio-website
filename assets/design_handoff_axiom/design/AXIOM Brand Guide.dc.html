01–03
Meaning, origin, philosophy

The principle everything else is built on.

Origin

From the Greek axiōma (ἀξίωμα) — something held worthy, accepted as self-evident — which entered modern international usage through Latin. In mathematics, logic and systems thinking an axiom is the foundational statement from which the rest of a system follows.

Interpretation

The foundation has to be right for anything above it to hold. That is the working method: structure before interface, logic before code, foundation before scale. It is what separates eleven years of shipped production work from decoration.

The tension

AXIOM is absolute; the octopus is adaptive. The identity lives in that contradiction — a rigid architectural system with one intelligent organism inside it. Rigid × fluid. System × adaptation. Logic × instinct.

05
The octopus

Eight arms, one nervous system. The octopus is the most credible animal metaphor available for multidisciplinary work: design, UX, front-end, technology, product, systems, leadership and communication running in parallel, coordinated from a single centre.

IntelligenceAdaptabilitySystem thinkingControlProblem solvingPrecision

This is conceptual meaning, never an infographic — the arms are never labelled. The surrounding language keeps it intellectual: no waves, anchors, ropes, compasses, ocean texture or Kraken references anywhere in the system. The octopus appears against grids and architecture, never against the sea.

09
Wordmark
decision open

The supplied reference sets AXIOM in Bellefair, a light didone-adjacent serif. It is elegant but fragile: the hairlines break up below 20px, and it pulls the brand towards fashion rather than systems. Three candidates, all tracked to 0.16em so the X sits at the optical centre of the word. Pick one.

Option A · Archivo — one voice with the UI
AXIOM
The wordmark and the interface are cut from the same family, so the brand never announces itself as a separate object. Squared terminals, closed apertures, unambiguous at 12px. The most systematic and the least distinctive.
Option B · Archivo Expanded — monumental
AXIOM
The same family opened to its widest width axis. Reads as engraved rather than typed — architectural, international, and still one type family in the build. Needs horizontal room, so the header uses the symbol alone below 900px.
Option C · Bellefair — as supplied
AXIOM
The reference as drawn. Intellectual and quiet, and it pairs naturally with the editorial serif already on the site. Hairline strokes are the risk: it needs a minimum of 22px on screen and disappears against photography.
Recommendation

Option B. The expanded width gives AXIOM the monumentality the organic symbol needs to sit against, it holds at every size the serif fails at, and it costs nothing extra in the build — one variable family covers wordmark, navigation and UI.

On the X: no intervention. It is already the optical centre and the only diagonal in the word — tracking is doing the work. Any cut, gap or overlap added to it would read as a gimmick against an organic symbol that is doing the expressive work already.

Clear space, minimum size, misuse
12 · Clear space
Clear space equals half the symbol's height on every side, measured from the artwork bounding box — not from the arm tips' visual centre. In the lockup the measure is taken from the widest element, usually the wordmark.
13 · Minimum size
40pxFull symbol, screen 16pxMicro mark, screen 18mmFull symbol, print 120pxHorizontal lockup, min width 180pxProfessional lockup, min width

✕Any gradient, glow, bevel or drop shadow ✕Outlined or stroke-only versions of the symbol ✕Rotating, mirroring or tilting the octopus ✕Waves, anchors, ropes, bubbles or water anywhere near it ✕Adding eyes, expression or character detail ✕Placing it over busy photography without a masked plane ✕Setting AXIOM in any typeface other than the chosen master ✕“AXIOM Studio”, “AXIOM Agency” or any suffix

17–20
Grid, rigid × organic, photography, surrealism
17 · Grid
12 columns, 24px gutter, 1320 max. Editorial content sits in 4–9, section numbers hang in column 1, technical labels align right in column 12. Asymmetry comes from which columns are left empty.
18 · Rigid × organic
The whole system is one idea: a perfect grid, entered by one organism. The grid is never distorted to accommodate it and the symbol is never geometricised to fit. They simply occupy the same frame, and the symbol is allowed to crop.
19–20 · Photography & surrealism
Use — contemporary architecture, glass, concrete, steel, structural shadow, dark interiors, dramatic natural light, unusual perspective.

Avoid — stock teams, handshakes, laptops, colourful startup photography, code screens, 3D blobs, anything maritime.

Surrealism — one organic presence inside one rational frame, at most once per page: a single arm crossing a grid line, the symbol half-masked behind a building edge, a curve derived from the mark cutting an otherwise orthogonal layout. Monochrome, no filters, never illustrated.
21
Motion
Easing
cubic-bezier(0.16, 1, 0.3, 1) for reveals; cubic-bezier(0.4, 0, 0.2, 1) for state. No overshoot, no elastic, no bounce.
Duration
120ms state · 320ms element · 520ms section · 640ms page transition. Preloader capped at 900ms and skipped on repeat visits.
Structural vocabulary
Clip-path wipes along a grid axis, line draws, mask reveals, opacity, translate under 24px. Interface motion runs on the grid, never diagonally.
Organic exception
The symbol alone may move off-axis: a slow mask reveal from the mantle outward, arms resolving last. Never swimming, never looping, never a cartoon. One occurrence per session.
Reduced motion
prefers-reduced-motion collapses every duration to 0ms and replaces reveals with a 120ms opacity fade. The preloader is bypassed.
Rule
Motion never delays access to the work. If an animation blocks reading for more than half a second, cut it.
